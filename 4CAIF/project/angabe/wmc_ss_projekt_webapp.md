# WMC – Individuelle Webapplikation (Sommersemester)

## Aufgabenstellung

Erstelle eine kleine Webapplikation mit HTML, CSS und JavaScript zu einem **selbst gewählten Thema**.

---

## Anforderungen (Pflicht)

| Bereich | Anforderung |
|---|---|
| HTML | Semantisches HTML |
| CSS | Styling mit CSS (Frameworks & KI erlaubt) |
| JavaScript | Mindestens **3 Interaktionen**: mind. 1 Ereignisbehandlung + 1 DOM-Modifikation |
| JavaScript | Strukturierung gemäß Vorlage mit **8 Punkten** |
| JavaScript | Verwendung eines **State-Objektes** |
| JavaScript | Speichern des States in **Local Storage** |
| KI | **Keine KI-Nutzung** bei der Implementierung der Pflichtanforderungen |

---

## Optionale Erweiterungen

- Komplexere Programmlogik
- Aufruf von **Web-APIs** (z. B. [public-apis](https://github.com/public-apis/public-apis))
- Verwendung von **Promises / async/await**

> **Hinweis:** KI-Nutzung ist bei optionalen Erweiterungen erlaubt/sinnvoll.  
> Saubere Abgrenzung empfohlen – z. B. als eigener Ordner/zweite Ausbaustufe abgeben.

---

## Beurteilung

- **Abgabe:** bis Ende Mai via Git
- **Präsentation:** Alle Stunden im Juni haben prüfungsimmanenten Charakter → Anwesenheit erforderlich
- Bei der Präsentation müssen Code erklärt, Fragen beantwortet und kleine Änderungen vorgenommen werden können

### Beurteilungskriterien (Priorität)

1. **Funktionalität** und sauberer Code
2. Design (nachrangig)

> Lieber weniger Umfang mit guter Erklärung als komplexe Lösung, die nicht erklärt werden kann.
